# IGRB: selective graph residual boosting for back-order prediction

This repository contains the compact, reproducible release for the IGRB study. It intentionally excludes trained checkpoints, per-seed prediction dumps, LaTeX auxiliary files, caches, exploratory rejected variants, and other intermediate artifacts. The retained `results/igrb_analysis` directory contains the final aggregated evidence reported in the manuscript.

## Repository structure

```text
hetst/                 Core simulator, models, experiments and analysis
tests/                 Integrity and leakage regression tests
data/                  Derived retail demand and provenance metadata
configs/               Audited configurations for the four benchmark cases
results/igrb_analysis/ Final aggregated CSV/JSON evidence only
paper/                 Final manuscript source, figures and generation scripts
docs/                  Protocol, recovered-code audit and completion report
```

## Installation

Python 3.12 was used. Create a clean environment:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m unittest discover -s tests -v
```

For a CPU-only PyTorch installation, install the pinned PyTorch build from `https://download.pytorch.org/whl/cpu` before the remaining requirements. GPU acceleration is optional.

## Data

The only external input is UCI Online Retail:

- DOI: https://doi.org/10.24432/C5BW33
- Original ZIP: https://archive.ics.uci.edu/static/public/352/online+retail.zip

The source contains sales transactions, not inventory states or observed back orders. The retained `data/retail_demand.npy` is the derived twelve-stream demand matrix and `data/retail_provenance.json` records its construction. Seasonal, intermittent and correlated cases are generated by `hetst/simulator.py`. All inventory states, disruptions and back-order labels are simulated.

## Reproduce the final study

Run the fixed benchmark:

```bash
python -m hetst.experiment_igrb --output results/igrb_final
```

Run independent demand records:

```bash
python -m hetst.experiment_igrb_generalization --output results/igrb_gen_s --cases seasonal
python -m hetst.experiment_igrb_generalization --output results/igrb_gen_i --cases intermittent
python -m hetst.experiment_igrb_generalization --output results/igrb_gen_c --cases correlated
```

Run the retained ablations and aggregate results:

```bash
python -m hetst.experiment_igrb --output results/igrb_errorweighted --cases seasonal,correlated --shifts none --skip-policy --error-weighting
python -m hetst.experiment_igrb --output results/igrb_noadi --cases intermittent,retail --shifts none --skip-policy --no-adi
python -m hetst.analyze_igrb
```

New executions create detailed checkpoint and prediction directories under `results/`. These are ignored by Git because they are reproducible intermediate artifacts.

```bash
pdflatex -interaction=nonstopmode -halt-on-error igrb_main.tex
pdflatex -interaction=nonstopmode -halt-on-error igrb_main.tex
```

The bibliography is embedded in `igrb_main.tex`; BibTeX is not required.

## Evidence boundaries

- The fixed benchmark uses five model seeds on one demand realization.
- Seasonal and correlated uncertainty uses ten independent demand records; intermittent uses five.
- The retail-driven case uses empirical demand only; topology, inventory and labels are simulated.
- IGRB improves most consistently under correlated demand and deliberately falls back to the local expert in sparse regimes.
- The historical Zenodo DOI predates this reconstruction and must not be used to reproduce the current numerical results.

See `docs/PROTOCOL.md` and `docs/RECOVERED_CODE_AUDIT.md` before interpreting or extending the experiments.
